# Feature Documentation

Feature briefs describe user-facing behavior before implementation. Every brief should link to the product principle it supports, define states and acceptance criteria, and identify data/privacy impact.

## Current Feature Areas

- Feeling-first movie discovery.
- Movie detail and TMDB metadata.
- Experience logging and Bud identity.
- Crew activity and community reactions.
- Authentication and session continuity.

Feature-specific documents should use the sprint template and live alongside the relevant delivery plan.
