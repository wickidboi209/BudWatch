# Roadmap

The roadmap is directional. Each sprint must preserve the core feeling-first discovery loop.

## Completed Foundation

- TMDB movie discovery and detail experience.
- Mood-led Home screen.
- Experience logging foundation.
- Community activity and placeholder crew foundation.
- Supabase authentication foundation.
- Motion and loading polish.

## Next Horizons

### Horizon 1: Durable Identity

- Persist experiences, Bud Scores, moods, and notes.
- Populate Profile metrics from member data.
- Add secure sign-out and account recovery.

### Horizon 2: Real Crew Social

- Create and manage crews.
- Follow or invite members with consent.
- Persist reactions and threaded comments.
- Add moderation and reporting.

### Horizon 3: Better Discovery

- Personalize recommendations from moods and experiences.
- Add search and filters without losing the feeling-first entry point.
- Introduce collaborative lists and watch sessions.

## Definition Of Ready

A sprint has a named user outcome, acceptance criteria, data/privacy impact, design notes, and a validation plan before implementation begins.
